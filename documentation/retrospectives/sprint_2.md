# 2. sprintin retrospektiivi

Retrospektiivi käytiin ensimmäistä kertaa etänä Zoomin välityksellä, retron pitäjänä toimi Jaakko.
Menetelmänä oli käytössä Start, Stop, Continue ja lisämausteena Act.

## Retrossa ilmi tullutta

Retrossa nousi esiin viime retroihin verrattuna enemmän huolenaiheita. Sprintin aikana koettiin, että tarvitsemme järkevämmän työnjaon,
selkeämmät user storyt ja tarkemman otteen ryhmän yhteisille tapaamisille, jotta aikaa ei hukkaantuisi projektin ulkopuolisista asioista keskustelemiseen.
Ajankäytön osalta toivottiin, että tapaamisissa pysyttäisiin paremmin sovitussa agendassa. Yhtenä ongelmana koettiin tilanteet, joissa yksi tiimin jäsen 
hoitaa koodaamisen muiden seuratessa vierestä. Tähän liittyen user storyjen luominen selkeämmäksi ja niiden reilu jakaminen jäsenten kesken auttavat
tilannetta seuraavissa sprinteissä. Jatkossa myös tarkoituksena kokeilla parikoodaamista. 

Positiivisena asioina esille tuotiin ryhmän sisäinen kommunikaatio.
